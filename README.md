# 노대원 홈페이지 — 시각 디자인 개편판

최종 수정: 2026-08-03 · 최신 CV 기준일: 2026-08-02

`plain HTML/` 을 바탕으로 시각 디자인을 다시 잡은 버전입니다. 컨셉 이미지의
크림 지면 + 코발트 강조 + 이름 중심 히어로를 기준으로 삼았습니다.
콘텐츠(항목 수·문구)는 원본과 동일하고, 구조와 타이포그래피만 바꿨습니다.

## 무엇이 바뀌었나

**타이포그래피**
- 한 페이지에 쓰이던 글자 크기 20종 → 8종. 본문 하한 16px, 보조 14px, 라벨 12px.
- 목록 페이지 본문이 12.5px → 16px.
- 국문·라틴을 한 패밀리로 통일. `Georgia, "Noto Serif KR"` 처럼 한 줄에서
  서체가 갈라지는 스택을 없앴습니다.
- 국문 자간 하한 −0.04em (기존 −0.095em 에서는 자모가 붙었습니다).

**레이아웃**
- `li { max-width: 75ch }` 제거. 목록 행이 컨테이너의 43% 만 쓰고 57% 를 비워 두던
  문제를 고쳤습니다. 목록 페이지 본문 폭은 60rem 으로 따로 잡았습니다.
- 행마다 반복 출력되던 `PUB`(76회) · `BOOK`(13회) 라벨 삭제.
- 책 표지를 1.53:1 가로 박스로 자르던 것을 `aspect-ratio: 2/3` 판형 그대로.
- 헤더를 2행 스택 → 1행(이름 · 세로선 · 직함 · 메뉴). 메뉴 11.5px → 13px.

**정보 구조**
- 서지 항목을 제목 / 수록지 / 날짜로 분리했습니다. 한 덩어리 문자열이던 것을
  나눠, 날짜 레일로 훑을 수 있습니다.
- 부속 메뉴를 목록 페이지 전체에 통일(평론·소개·저서에는 없었습니다).
- 섹션 제목에 항목 수 표시.
- 날짜가 없는 목록(교과목, 연구 분야, 연재 서평)은 날짜 레일 없이 단순 목록으로.
- `<제주의소리> 서평 (BOOK世通 연재)` 는 항목이 아니라 뒤따르는 24편의 묶음
  제목이었으므로 소제목으로 올렸습니다.
- `<footer>` 를 `<main>` 밖으로, `aria-current` 를 전 페이지에.
- `about.html` 의 `h2 → h4` 단계 건너뜀을 `h3` 으로 교정.

**접근성**
- `--muted` 를 `#7a7671` → `#6b6862`. 이전 값은 지면 대비 3.9:1 로 AA 미달이었습니다.
  현재 모든 본문 텍스트가 4.8:1 이상입니다.
- `prefers-reduced-motion` 을 `!important` 로 덮어써서 무한히 깜빡이던 히어로 커서를
  없앴습니다. `!important` 는 동작 축소 블록 3개만 남았습니다(사용자 설정이 이겨야 하므로).
- 1440 / 900 / 390px 에서 가로 스크롤 없음, 12px 미만 텍스트 없음.

**CSS**
- 누적된 덮어쓰기 레이어 18겹 → 5개 구역(TOKENS / BASE / COMPONENTS / PAGES /
  RESPONSIVE). 미디어쿼리 밖에서 같은 선택자를 두 번 열지 않습니다.
- 1–448행에 있던, 뒤 레이어에 전부 덮여 있던 원래 CV 스타일 시스템 폐기.

**에셋**
- `assets/portrait/hero-network.webp` / `.jpg` 를 새로 만들었습니다.
  원본 `hero-network-banner.jpg` 는 좌측 42% 가 단색 판이고 경계에 수직 이음선,
  그리고 잘린 검정 슬래브가 남아 있었습니다. `portrait-network.jpg` 를 바탕으로
  슬래브를 지우고, 배경을 지면색(#f2eee8)에 맞추고, 좌측 110px 을 알파로
  페이드했습니다. 원본 두 파일은 그대로 남겨 두었습니다.

## 아직 남은 일

1. **폰트 self-host** — 지금은 시스템 스택입니다(`Pretendard → Apple SD Gothic Neo →
   맑은 고딕 → Noto Sans KR`). 방문자 PC 에 Pretendard 가 없으면 대체 서체로
   보입니다. `assets/fonts/` 에 서브셋 `woff2` 를 넣고 `styles.css` 상단의
   `@font-face` 주석을 해제하면 모든 방문자가 같은 화면을 봅니다.
   (Pretendard · Noto 모두 OFL 이지만 배포 전 라이선스 확인을 권합니다.)
2. **메뉴 8개 → 5개** — 컨셉 이미지는 연구 / 저서·논문 / 강의 / CV / 연락 5개입니다.
   줄이려면 평론·소개·English 의 자리를 옮기는 콘텐츠 결정이 필요해 손대지 않았습니다.
   크기와 헤더 1행 정리는 이미 반영되어 있습니다.
3. **히어로 이미지 해상도** — 원본이 885×650 이라 고해상도 화면에서는 다소
   부드럽게 보입니다. 더 큰 원본이 있으면 교체를 권합니다.
4. **표시용 서체 방향** — 지금은 고딕(컨셉 기준)입니다. 세리프를 원하면
   `--sans` 대신 self-host 한 `Noto Serif KR` 을 **단독으로** 쓰면 됩니다.

- 소개 — 학력·경력·수상 / 교육 경력 / 학술 봉사
- 저서 — 단행본 / 공동 저서

## 공개 원칙

- 연구비 금액, 전화번호, 상세 주소는 공개 목록에서 제외
- 연구과제는 과제명·기간·지원 기관·연구책임/공동연구 역할만 표시
- `CV` 는 전체 메뉴의 허브

동작합니다. `.webp` 를 쓰는 히어로 이미지는 `<picture>` 로 `.jpg` 대체가 있습니다.
