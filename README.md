# 노대원 홈페이지 — plain HTML 테스트 버전

최종 수정: 2026-08-03

화려한 디자인과 기능을 제외하고, 최신 CV의 공개 가능한 전체 내용을 메뉴별로 배치한 정적 HTML 테스트 버전입니다.

## 메뉴

- 홈
- 강연·매체
- 저서
- 연구
- 평론
- 경력
- CV
- English

`연구` 페이지의 서브 메뉴:

- 논문·이슈페이퍼·리포트
- 연구과제·공동연구
- 학술발표·토론

`강연·매체` 페이지의 서브 메뉴:

- 대학 강연
- 대중 강연
- 언론 기고·인터뷰
- 방송 출연

## 반영 원칙

- 최신 CV 기준일: 2026-08-02
- 단행본과 공동 저서는 `저서` 페이지에 통합
- 논문과 이슈페이퍼·리포트는 `연구` 페이지에 통합
- 학술발표·토론은 `연구` 페이지로 이동
- 강연·매체의 대학 강연·대중 강연·언론 기고·인터뷰·방송 출연은 페이지 내 서브 메뉴로 분리
- 연구과제는 과제명·기간·지원 기관·연구책임/공동연구 역할을 표시
- 연구비 금액, 전화번호, 상세 주소는 공개 목록에서 제외
- 전체 목록은 각 하위 메뉴 페이지에서 확인하고 `CV`는 전체 메뉴의 허브로 사용

## 실행

`index.html`을 브라우저로 열어 확인합니다.
## 브랜드 홈

공통 헤더·푸터와 코발트 블루 브랜드 시스템이 모든 페이지에 적용되어 있습니다. 홈은 원본 프로필 사진을 ssets/portrait/portrait.jpg에서, 책 표지는 ssets/books/에서 읽습니다. 원본 자산이 준비되기 전에는 홈 히어로가 단색 대체 패널로 표시됩니다.

브라우저에서 index.html을 직접 열어 확인하고, 구조 회귀 검사는 프로젝트 루트에서 다음 명령으로 실행할 수 있습니다.

python tests/run_public_homepage_checks.py
